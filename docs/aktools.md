# AKTools 详细文档

## 介绍 {#intro}

[AKTools](https://github.com/akfamily/aktools) 是一款用于快速搭建 [AKShare](https://github.com/akfamily/akshare) HTTP API 的工具。只需一行命令即可启动 HTTP 服务，让原本只服务于 Python 用户的开源财经数据接口库 AKShare 突破编程语言的限制：无论您使用的是 C/C++、Java、Go、Rust、Ruby、PHP、JavaScript、R、MATLAB 等编程语言，都可以快速、轻松地获取财经数据，助力您更好地展开数据科学工作。

- [AKShare](https://github.com/akfamily/akshare) 是使用广泛的开源财经数据接口库，覆盖股票、期货、期权、基金、债券、外汇、宏观等数据，并提供详实的 [AKShare 文档](https://akshare.akfamily.xyz/)。
- [FastAPI](https://fastapi.tiangolo.com/) 是 Python 生态中最受欢迎的 Web 框架之一。AKTools 基于 FastAPI 构建，并自动生成可在线调试的接口文档。

AKTools 本身几乎不包含业务逻辑：请求 `/api/public/<接口名>` 时，它调用同名的 AKShare 接口，再把返回的 `pandas.DataFrame` 转成 JSON。因此**接口有哪些、参数怎么填、数据是什么含义，都以 [AKShare 数据字典](https://akshare.akfamily.xyz/data/index.html) 为准**。

## 安装 {#install}

### 安装要求

- Python 3.11 及以上（64 位）
- 64 位操作系统

详细要求以 [AKShare 安装指导](https://akshare.akfamily.xyz/installation.html) 为准。

### 安装与升级

```shell
pip install aktools
```

AKShare 的数据接口会随上游网站的变化频繁更新，遇到问题时请先把 AKShare 和 AKTools 都升级到最新版：

```shell
pip install akshare aktools --upgrade -i https://pypi.org/simple
```

### 查看版本

在命令行中查看：

```shell
python -m aktools --version
```

在 Python 中查看：

```python
import aktools

print(aktools.__version__)
```

服务启动后，也可以访问 `http://127.0.0.1:8080/version`，同时查看当前安装的和 PyPI 上最新的 AKShare、AKTools 版本：

```json
{"ak_current_version":"1.20.0","ak_latest_version":"1.20.2","at_current_version":"0.0.95","at_latest_version":"0.0.95"}
```

## 启动服务 {#start}

### 命令行启动

在已安装 AKTools 的 Python 环境中打开命令行（Windows 下可以使用 `cmd` 或 PowerShell），输入：

```shell
python -m aktools
```

看到如下信息即表示启动成功：

```text

点击打开 HTTP API 主页：http://127.0.0.1:8080/
点击打开接口导览：http://127.0.0.1:8080/docs
INFO:     Started server process [10472]
INFO:     Waiting for application startup.
INFO:     Application startup complete.
INFO:     Uvicorn running on http://127.0.0.1:8080 (Press CTRL+C to quit)
```

此时在浏览器地址栏输入 `http://127.0.0.1:8080/api/public/tool_trade_date_hist_sina`，即可验证服务是否连通（该接口为新浪交易日历，无需参数且较为稳定）。按 `Ctrl+C` 停止服务。

### 启动参数 {#options}

| 参数 | 简写 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `--host` | `-H` | `127.0.0.1` | 监听地址 |
| `--port` | `-P` | `8080` | 监听端口 |
| `--auto` | `-A` | 关闭 | 启动后自动打开浏览器 |
| `--version` | `-v` | — | 查看 AKTools 版本 |
| `--help` | — | — | 查看帮助 |

例如：

```shell
python -m aktools --host 0.0.0.0 --port 8888
```

!!! note "监听地址与访问地址"

    默认的 `127.0.0.1` 只允许本机访问。需要让局域网或其他机器访问时，请把 `--host` 设为 `0.0.0.0`，其他机器再通过 `http://<本机 IP>:8888` 访问。`0.0.0.0` 只是“监听所有网卡”的意思，不能作为访问地址使用。

### 服务地址 {#endpoints}

| 地址 | 说明 |
| --- | --- |
| `/` | 主页，展示服务地址、版本信息和简要的使用说明 |
| `/docs` | 接口导览（Swagger UI），可在线调试接口 |
| `/version` | 当前与最新的 AKShare、AKTools 版本 |
| `/api/public/{接口名}` | 获取数据，详见[调用规则](#usage) |
| `/api/show-temp/{接口名}` | 用 [PyScript](https://pyscript.net/) 在浏览器中获取并展示该接口的数据，并提供 JSON 下载 |
| `/api/show` | 上述 PyScript 数据展示页的演示，展示 `tool_trade_date_hist_sina` 接口的数据 |

PyScript 数据展示页在浏览器中运行 Python：首次打开时，浏览器需要从 jsDelivr CDN 下载 Pyodide 与 pandas（数十 MB），因此需要能访问外网，加载可能需要几十秒。

## 调用规则 {#usage}

AKTools 把 HTTP 请求一一对应地翻译成 AKShare 接口调用：

```text
GET /api/public/{接口名}?{参数1}={值1}&{参数2}={值2}
        ↓
akshare.{接口名}(参数1="值1", 参数2="值2")
```

- **接口名**与 AKShare 的函数名完全一致，例如 `stock_zh_a_hist`。
- **参数**以查询字符串传递，参数值不需要加引号；多个参数之间用 `&` 连接。
- 不传的参数使用 AKShare 接口的默认值。

### 无参数接口

例如 `ak.tool_trade_date_hist_sina()` 用于获取新浪财经的交易日历，直接访问即可：

```text
http://127.0.0.1:8080/api/public/tool_trade_date_hist_sina
```

### 带参数接口

例如 `ak.stock_zh_a_hist()` 用于获取 A 股历史行情。获取 `symbol="600000"` 的数据：

```text
http://127.0.0.1:8080/api/public/stock_zh_a_hist?symbol=600000
```

同时指定多个参数：

```text
http://127.0.0.1:8080/api/public/stock_zh_a_hist?symbol=600000&period=weekly&start_date=20240101&end_date=20241231&adjust=qfq
```

注意 `?symbol=600000` 中的参数值不带 `"` 号。

### 返回格式

成功时返回由 DataFrame 按行转换得到的 JSON 数组，每一行是一个对象，字段名与 AKShare 返回的列名一致；日期时间字段为 ISO 8601 格式：

```json
[
  {"trade_date": "1990-12-19T00:00:00.000"},
  {"trade_date": "1990-12-20T00:00:00.000"},
  {"trade_date": "1990-12-21T00:00:00.000"}
]
```

### 错误与状态码 {#status-codes}

失败时返回 `{"error": "错误信息"}`：

| 状态码 | 含义 | 处理建议 |
| --- | --- | --- |
| `200` | 成功 | — |
| `404` | 接口名不存在、接口调用出错（如参数错误）或接口返回空数据 | 升级 AKShare，并对照 AKShare 文档检查接口名和参数 |
| `502` | 无法访问上游数据源 | 检查网络和代理设置，见[常见问题](#faq-502) |

可以根据状态码区分是用法问题还是网络问题。

### Python

```python
import pandas as pd
import requests

url = "http://127.0.0.1:8080/api/public/stock_zh_a_hist"
params = {
    "symbol": "000001",
    "period": "daily",
    "start_date": "20240101",

    "adjust": "qfq",
}

r.raise_for_status()
df = pd.DataFrame(r.json())
print(df)
```

### Rust

依赖 `reqwest`（启用 `blocking` 与 `json` 特性）和 `serde_json`：

```rust
use reqwest::blocking;
use serde_json::Value;

const URL: &str = "http://127.0.0.1:8080/api/public";

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let params = [
        ("symbol", "000001"),
        ("period", "daily"),
        ("start_date", "20240125"),
        ("end_date", "20240126"),
        ("adjust", ""),
    ];
    let resp = blocking::Client::new()
        .get(format!("{URL}/stock_zh_a_hist"))
        .query(&params)
        .send()?;

    if resp.status().is_success() {
        let data: Value = resp.json()?;
        println!("{data:#?}");
    } else {
        eprintln!("请求失败，状态码为：{}", resp.status());
    }
    Ok(())
}
```

## 部署 {#deploy}

### 生产环境 {#production}

`python -m aktools` 启动的是单进程的 Uvicorn，适合本地使用。生产环境建议用 Gunicorn 管理多个 Uvicorn worker 进程，提高并发处理能力：

```shell
pip install gunicorn uvicorn-worker
gunicorn aktools.main:app --bind 0.0.0.0:8080 --workers 4 --worker-class uvicorn_worker.UvicornWorker
```

`--workers` 通常设为 CPU 核数的 2～4 倍，更多配置请参考 [Gunicorn 文档](https://gunicorn.org/)。

!!! warning "安全提示"

    AKTools 不带鉴权和限流功能，任何能访问到服务的人都可以调用全部接口。如果服务需要暴露到公网，请在前面加一层带鉴权的反向代理（如 Nginx），或者只在内网中使用。

### Docker {#docker}

#### 构建镜像

仓库中提供了 [Dockerfile](https://github.com/akfamily/aktools/blob/main/Dockerfile)，构建时会安装 PyPI 上最新的 AKShare 和 AKTools。下载该文件后，在其所在目录执行：

```shell
docker build -t aktools .
```

国内网络环境下，可以指定 PyPI 镜像源加速构建：

```shell
docker build --build-arg PIP_INDEX_URL=https://mirrors.aliyun.com/pypi/simple/ -t aktools .
```

启动容器：

```shell
docker run -d -p 8080:8080 --name aktools aktools
```

镜像默认以 Gunicorn + Uvicorn worker 的方式运行，与[生产环境](#production)的部署方式一致。如需改用普通模式启动：

```shell
docker run -d -p 8080:8080 --name aktools aktools python -m aktools --host 0.0.0.0 --port 8080
```

启动后访问 `http://127.0.0.1:8080/api/public/tool_trade_date_hist_sina`，能获取到数据即表示部署成功。

#### 升级镜像

镜像中的 AKShare 版本在构建时固定。需要升级时，加上 `--no-cache` 重新构建，再用新镜像重建容器即可：

```shell
docker build --no-cache -t aktools .
docker rm -f aktools
docker run -d -p 8080:8080 --name aktools aktools
```

## 常见问题 {#faq}

### 接口返回 502 且提示“访问上游数据源失败” {#faq-502}

AKTools 本身只是把请求转发给 AKShare，数据由东方财富、新浪财经等上游网站提供。当返回如下错误时：

```text
{"error": "访问上游数据源失败，请检查网络或代理设置（如 HTTP_PROXY/HTTPS_PROXY 环境变量）：..."}
```

通常是运行 AKTools 的机器**无法访问上游数据源**，而不是 AKTools 或接口本身的问题。常见原因与排查方法：

1. 本机配置了 HTTP 代理，但代理不可用。报错中若出现 `ProxyError`、`Unable to connect to proxy` 即属此类。请检查并按需清除代理环境变量，然后重启服务：

    ```shell
    # Linux / macOS
    unset HTTP_PROXY HTTPS_PROXY ALL_PROXY
    # Windows PowerShell
    Remove-Item Env:HTTP_PROXY, Env:HTTPS_PROXY, Env:ALL_PROXY
    ```

    若必须经代理访问外网，可通过 `NO_PROXY` 排除内网地址，或确认代理本身可用。

2. 网络不通或上游网站临时不可达：可先用 `tool_trade_date_hist_sina` 这类轻量接口测试连通性，或稍后重试。

3. 部分接口对网络环境（如需境内网络）有要求，请参考 [AKShare 文档](https://akshare.akfamily.xyz/) 中对应接口的说明。

### 接口返回 404 {#faq-404}

按错误信息分别处理：

- **未找到该接口**：接口名拼写错误，或当前安装的 AKShare 版本还没有这个接口。请升级 AKShare，并在 AKShare 文档中确认接口名。
- **调用接口出错**：通常是参数名或参数值不正确。请对照 AKShare 文档检查参数，也可以在 Python 中直接调用同名接口，确认问题是否出在 AKShare。
- **该接口返回数据为空**：参数组合没有对应的数据，例如日期范围内没有交易日。

### 其他机器无法访问服务 {#faq-remote}

1. 启动时需要指定 `--host 0.0.0.0`，默认的 `127.0.0.1` 只允许本机访问。
2. 检查防火墙或云服务器的安全组是否放行了对应端口。
3. 使用 Docker 时，确认 `docker run` 带上了 `-p 8080:8080` 端口映射。

### 日志文件在哪里 {#faq-log}

AKTools 在**启动服务时所在的工作目录**下写入 `aktools_log.log`，每天零点轮转一次，保留最近 7 天。部署到 Vercel 时写入 `/tmp/aktools_log.log`。

### 数据有误或接口报错，应该去哪里反馈 {#faq-feedback}

先在 Python 中直接调用同名的 AKShare 接口：

- 直接调用 AKShare 也有同样的问题：请到 [AKShare Issues](https://github.com/akfamily/akshare/issues) 反馈。
- 只有通过 AKTools 访问时才出问题：请到 [AKTools Issues](https://github.com/akfamily/aktools/issues) 反馈，并按 Issue 模板提供版本、启动命令、请求 URL 与完整报错。
